PRIYA ASCII MOTION — GitHub Pages

1. Create a new repository on GitHub (for example: priya-motion).
2. Upload BOTH files from this folder: index.html and priya.jpg.
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait a minute or two. Your site will appear at:
   https://YOUR-USERNAME.github.io/priya-motion/

Keep index.html and priya.jpg in the same folder. The animation is designed to run in a modern mobile browser too.
